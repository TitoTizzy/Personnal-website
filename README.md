# Myrtho Charles Portfolio

Portfolio statique multipage de Bui Gerry Myrtho Charles, orienté IA, développement frontend, fintech et gestion de comptes.

## Pages

- `index.html` : accueil, positionnement et projets vedettes.
- `about.html` : profil, expertise et méthode de travail.
- `projects.html` : études de cas et liens publics.
- `experience.html` : parcours professionnel, formation et certifications.
- `contact.html` : canaux directs et formulaire FormSubmit.
- `merci.html` : confirmation après soumission du formulaire.

## Stack

- HTML5
- CSS3 responsive
- JavaScript vanilla
- Google Fonts
- Google Translate widget
- FormSubmit pour le formulaire de contact

## Lancement local

Depuis le dossier du projet :

```bash
python -m http.server 8765
```

Puis ouvrir :

```text
http://localhost:8765/
```

## Notes de publication

- Les images affichees dans le site utilisent des versions WebP optimisees.
- Les fichiers `robots.txt`, `sitemap.xml`, `site.webmanifest` et les balises Open Graph sont inclus pour ameliorer le SEO et le partage social.
- Si le site utilise un domaine personnalise, mettre a jour les URLs absolues dans les balises `canonical`, Open Graph, `robots.txt` et `sitemap.xml`.
